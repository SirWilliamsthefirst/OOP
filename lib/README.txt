Place the following JAR files in this folder before building:

1. postgresql.jar
   Download: https://jdbc.postgresql.org/download/
   (any recent version, e.g. postgresql-42.7.3.jar — rename to postgresql.jar)

2. bcrypt.jar
   Download: https://search.maven.org/search?q=at.favre.lib+bcrypt
   Version: at.favre.lib:bcrypt:0.10.2 — rename to bcrypt.jar

3. jakarta.mail.jar
   Download: https://search.maven.org/search?q=com.sun.mail+jakarta.mail
   Version: com.sun.mail:jakarta.mail:2.0.1 — rename to jakarta.mail.jar

After placing all 3 JARs here, open the project in NetBeans and click Run.
